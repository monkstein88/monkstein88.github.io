# Monk Monkstein — Hardware & Embedded Portfolio Webpage

A single-page developer portfolio for **Monk Monkstein**, focused on FPGA design, RTL development, embedded systems, soft processors, and Linux-based hardware projects.

The site uses an electronics-lab visual language with signal-flow diagrams, circuit-inspired styling, hardware status indicators, and links to related GitHub repositories and technical documentation.

## Features

- Responsive single-page portfolio
- FPGA and embedded hardware visual theme
- Inline SVG hardware-lab illustrations
- Signal-flow section: `INPUT → DESIGN → VERIFY → DEPLOY`
- Featured build section
- Filterable project cards for:
  - RTL
  - Embedded
  - Linux
- GitHub repository and documentation links
- GitHub profile image integration
- Light/dark theme toggle
- System color-scheme support
- Reduced-motion support
- No frameworks, build tools, or external dependencies
- Suitable for GitHub Pages hosting

## Featured Projects

### Altera IP Cores

Reusable SystemVerilog cores for Quartus and Platform Designer projects.

- [Repository](https://github.com/monkstein88/altera-ip-cores)
- [Quartus Prime documentation](https://www.intel.com/content/www/us/en/products/details/fpga/development-tools/quartus-prime.html)

### NIOS-V Examples

Practical NIOS-V processor examples for FPGA development and Terasic DE0-NANO workflows.

- [Repository](https://github.com/monkstein88/niosv-example-projects)
- [NIOS-V documentation](https://www.intel.com/content/www/us/en/docs/programmable/683632/current/nios-v-processor.html)

### Tang Nano 9K Labs

FPGA tutorial exercises and experiments built for the Sipeed Tang Nano 9K board.

- [Repository](https://github.com/monkstein88/sipeed-tang-nano-9k-lushay-labs)
- [Tang Nano documentation](https://www.sipeed.com/tangnano)

### QMTECH C5SOC Linux

A build environment for generating U-Boot and Linux images for the QMTECH C5SOC platform.

- [Repository](https://github.com/monkstein88/qmtech-c5soc-kfb-linux-build-env)
- [Linux documentation](https://www.kernel.org/doc/html/latest/)
